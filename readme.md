<b>Програма виконує конвертацію температури між шкалами Цельсія та Фаренгейта
</b>

Користувачу пропунується обрати один з варінтів 1 або 2.
На клавіатурі він вводить 1 або 2.

Потім користувач з клавіатури вводить значення температури
і саме це значення перераховувається у відповідну величину

1. Якщо ввів 1 то це буде переведення з Цельсія -> Фаренгейт
2. якщо ввів 2 то це буде переведення з Фаренгейт -> Цельсія
3. якщо ж користувач ввів щось інше то отримує результат Invalid choice
